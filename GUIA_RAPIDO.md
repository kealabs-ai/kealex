# 📖 Guia Rápido — Kealex AI Platform

## 🎯 Para Advogados

### 1. **Processos & Fases**
- Clique em **"Novo Processo"** para cadastrar um caso
- Expanda a seção **"Fases"** para ver a esteira de progresso
- Clique em **"Avançar Fase"** para mover o processo para a próxima etapa
- Gere **"Guia de Pagamento"** para custas processuais

### 2. **Intimações & DJE**
- Clique em **"Varrer Diários"** para buscar novas publicações
- A IA resume automaticamente cada intimação
- Marque como **"Lida"** quando revisar
- Veja o prazo calculado automaticamente

### 3. **Calendário de Prazos**
- Todos os prazos aparecem em ordem de urgência
- Alertas em vermelho para prazos vencendo em 7 dias
- Clique em **"Novo Prazo"** para adicionar manualmente

### 4. **Audiências Estratégicas**
- Cadastre audiências com data, local e partes
- Clique em **"Gerar IA"** para criar roteiro automático
- O roteiro inclui perguntas para testemunhas e teses de blindagem
- Expanda para ver o roteiro completo

### 5. **Gestão Financeira**
- Veja o gráfico de tendências (receitas vs despesas)
- Cadastre honorários com vencimento
- Alertas automáticos para pagamentos atrasados
- Exporte relatórios de faturamento

### 6. **Modelos e Peças**
- Acesse biblioteca de minutas
- Clique em um modelo para abrir no editor
- Customize e baixe em .docx

### 7. **Clientes & CRM**
- Gerencie dados de outorgantes
- Histórico de processos por cliente
- Contatos e observações

### 8. **Kealex AI Hub** ⭐
- **Chat**: Faça perguntas jurídicas
- **Editor**: Veja o documento sendo gerado em tempo real
- **Sugestões**: Clique em prompts sugeridos para começar
- **Ações Rápidas**: "Redija uma petição para...", "Qual o prazo para..."
- **Copiar/Baixar**: Copie o texto ou baixe em .docx

## 🆘 Troubleshooting

### Chat não funciona?
- Verifique se a chave da API está configurada em Admin > Config. IA
- Teste a conexão em Admin > Debug API

### Intimações não aparecem?
- Clique em "Varrer Diários" para sincronizar
- Verifique se há publicações recentes no DJe

### Gráfico não carrega?
- Recarregue a página
- Verifique se há dados de honorários cadastrados
