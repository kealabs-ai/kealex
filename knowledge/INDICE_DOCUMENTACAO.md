## 📝 Notas Importantes

⚠️ **Antes de Instalar**
- Certifique-se de ter Node.js 18+
- Backend FastAPI deve estar rodando na porta 8000
- Configure variáveis de ambiente corretamente

⚠️ **Antes de Usar**
- Faça login com credenciais de teste
- Explore cada módulo em ambiente de desenvolvimento
- Não use dados reais até estar em produção

⚠️ **Antes de Deploy**
- Todos os testes devem passar
- SSL/HTTPS deve estar configurado
- Backup de dados deve estar ativo
